Your 7 Challenges

What You'll Do

Each activity builds on the last. Start at #1 and work your way to Cyber Hero!

🔑 Passwords

Test invented passwords to discover what makes them strong or weak — and how long a computer would take to crack them.

🎣 Phishing Detection

Analyze suspicious emails and decide: real or scam? Train your eye like a real security analyst.

🛡️ Security Quiz

Answer real-world scenarios and see if your instincts match what the pros recommend.

💉 SQL Injection

Use a famous hacker trick to bypass a pretend login screen and understand why secure coding matters.

📜 XSS Attack

Try to inject code into a webpage and see how sanitization stops the attack.

🔐 Encryption

Write secret messages using a Caesar cipher — the same idea behind modern encryption algorithms.

💻 Linux Terminal

Navigate a simulated Linux system using the same command-line tools real cybersecurity pros use daily.
