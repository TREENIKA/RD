Activity 7: Command Line Explorer

Linux Terminal Adventures!

Ready to explore the secret language of computers? This activity lets you try out a Linux Terminal, which is like talking directly to a computer using special commands instead of clicking buttons. You'll learn some basic commands that real cybersecurity pros use every day. It's like being a digital explorer, discovering what's inside a computer's brain!

Linux is an operating system — just like Windows or macOS — but it's free, open-source, and used by millions of servers, phones (Android is based on Linux!), and supercomputers around the world.

The terminal (or command line) lets you control the computer by typing commands instead of clicking icons. Think of it like the difference between texting instructions vs. using a touchscreen — both work, but typing is often faster and more powerful for experts.

Commands to try:
• ls — list files in the current folder
• pwd — show where you are in the file system
• whoami — print the current user
• mkdir myfolder — create a new folder
• cat notes.txt — read a file

Cybersecurity professionals use Linux terminals every single day to investigate hacks, run security tools, and manage servers!
